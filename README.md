# M33_Iot
# เอกสารข้อกำหนดโครงการ (Project Specification)
## โครงการ: เว็บไซต์พอร์ตโฟลิโอส่วนตัวสำหรับสมัครเข้าศึกษาต่อ คณะแพทยศาสตร์ มหาวิทยาลัยเชียงใหม่ (แพทย์ มช.)

### 1. ข้อมูลทั่วไป (General Information)
*   **ชื่อโครงการ:** CMU Medical Student Web Portfolio
*   **เจ้าของโครงการ:** นักเรียนชั้น ม.6 (ผู้สมัครเข้าศึกษาต่อ)
*   **กลุ่มเป้าหมาย (Target Audience):** คณะกรรมการคัดเลือกนักเรียนเข้าศึกษาต่อ คณะแพทยศาสตร์ มหาวิทยาลัยเชียงใหม่ (TCAS)
*   **จุดประสงค์ (Objective):** เพื่อนำเสนอประวัติส่วนตัว ทักษะความสามารถ กิจกรรมจิตอาสา โครงงานวิทยาศาสตร์ และศักยภาพทางวิชาชีพแพทย์ ในรูปแบบเว็บไซต์หน้าเดียว (One-Page Website) ที่ทันสมัย สะท้อนจิตวิญญาณหมอสวนดอก

### 2. เทคโนโลยีที่ใช้ (Tech Stack)
*   **HTML5:** โครงสร้างหลักของเว็บไซต์
*   **CSS3 (Tailwind CSS via CDN):** สำหรับการจัดการรูปแบบและการแสดงผลอย่างรวดเร็วและเป็นมาตรฐาน
*   **JavaScript (Vanilla JS):** สำหรับฟังก์ชันพื้นฐาน เช่น Smooth Scrolling และ Mobile Menu Toggle โดย **ไม่ใช้** Framework (เช่น React หรือ Vue)
*   **สภาพแวดล้อมการพัฒนา (Development Environment):** GitHub Codespaces

### 3. แนวทางการออกแบบ (Design & UI/UX Guidelines)
*   **Theme & Color Palette (โทนสีเอกลักษณ์ แพทย์ มช.):**
    *   **Primary Color:** สีเขียวสวนดอก (Suan Dok Medical Green - `#1E5631` หรือ `#006837`) สื่อถึงการแพทย์ สุขภาพ และอัตลักษณ์คณะแพทยศาสตร์ มช.
    *   **Secondary Color:** สีขาวอมเทา/เทาอ่อน (Clean Clinical Grey/Light Slate) สื่อถึงความสะอาด สะอาดตา และความมั่นคงทางการแพทย์
    *   **Accent Color:** สีทองดอกทองกวาว/เหลืองอบอุ่น (`#D4AF37` หรือ `#E5A93C`) สำหรับดึงดูดสายตาในจุดสำคัญ (Highlights / Call to Action)
*   **Typography:** ฟอนต์ที่อ่านง่าย สไตล์ Modern Minimal (เช่น `Prompt`, `Noto Sans Thai` หรือ `Sarabun`)
*   **Responsiveness:** รองรับการแสดงผลทุกหน้าจอ (Mobile-first approach, Tablet, Desktop) อย่างสมบูรณ์ 100%

### 4. โครงสร้างและส่วนประกอบของหน้าเว็บ (Website Sections)
โค้ดทั้งหมดจะถูกรวบรวมไว้ในไฟล์ `index.html` เพียงไฟล์เดียว แบ่งออกเป็นส่วนๆ ดังนี้:

#### 4.1 Header & Navigation (แถบเมนูด้านบน)
*   **ลักษณะ:** Sticky Navbar (ติดอยู่ด้านบนเสมอเมื่อเลื่อนหน้าจอ)
*   **องค์ประกอบ:** โลโก้ข้อความ "CMU Med Applicant" หรือชื่อย่อ (ฝั่งซ้าย), ลิงก์ไปยังส่วนต่างๆ (ฝั่งขวา)
*   **ฟังก์ชัน:** Smooth Scrolling เมื่อคลิกเมนู, มี Hamburger Menu สำหรับหน้าจอมือถือ

#### 4.2 Hero Section (ส่วนต้อนรับ)
*   **ลักษณะ:** แสดงผลเต็มหน้าจอ (Full-height) พร้อมภาพลักษณ์ที่น่าเชื่อถือ อบอุ่น
*   **องค์ประกอบ:**
    *   ภาพพื้นหลังหรือรูปโปรไฟล์นักเรียนในชุดนักเรียน/ชุดกาวน์ฝึกงานที่ดูเรียบร้อย สดใส
    *   ข้อความพาดหัว (Headline): ชื่อ-นามสกุล ผู้สมัคร
    *   สโลแกน (Sub-headline): "M.D. Candidate @ CMU | มุ่งมั่นสู่การเป็นแพทย์เพื่อชุมชนและสังคม"
    *   ปุ่ม Call-to-Action: "สำรวจผลงานและกิจกรรม" (เลื่อนไปที่ส่วน Projects/Activities)

#### 4.3 About Me (แนะนำตัวและแรงบันดาลใจ)
*   **ลักษณะ:** เลย์เอาต์แบบ 2 คอลัมน์ (รูปภาพ 1 ฝั่ง, ข้อความ 1 ฝั่ง สำหรับ Desktop)
*   **องค์ประกอบ:** ข้อความแนะนำตัวสั้นๆ อธิบายถึงความมุ่งมั่น แรงบันดาลใจที่อยากเรียนแพทย์ มช. ทัศนคติต่อวิชาชีพแพทย์ และเป้าหมายในการพัฒนาสุขภาพของประชาชน

#### 4.4 Skills & Competencies (ทักษะและศักยภาพ)
*   **ลักษณะ:** นำเสนอทักษะในรูปแบบ Progress Bar, Badge Tags หรือ Icon Grid
*   **องค์ประกอบทักษะที่ควรเน้น:**
    *   **วิชาการ (Academic):** ชีววิทยา (Biology), เคมี (Chemistry), ภาษาอังกฤษทางการแพทย์ (Medical English)
    *   **ทักษะวิชาชีพและจิตอาสา (Medical Soft Skills):** การรับฟังด้วยความเข้าใจ (Empathy & Active Listening), การแก้ปัญหาเฉพาะหน้า (Critical Thinking), การทำงานร่วมกับผู้อื่น (Teamwork)

#### 4.5 Projects & Activities (ผลงาน ผลงานวิจัย และกิจกรรม)
*   **ลักษณะ:** เลย์เอาต์แบบ Card Grid (1 คอลัมน์บนมือถือ, 3 คอลัมน์บน Desktop)
*   **องค์ประกอบในแต่ละ Card:**
    *   รูปภาพกิจกรรม/ผลงาน (Thumbnail)
    *   ชื่อโครงงาน/กิจกรรม (เช่น ค่ายอยากเป็นหมอ มช., งานวิจัยสมุนไพรท้องถิ่น, กิจกรรมจิตอาสาโรงพยาบาลชุมชน)
    *   คำอธิบายสั้นๆ (บทบาทหน้าที่ สิ่งที่ได้เรียนรู้ และผลลัพธ์)
    *   **ใส่ตัวอย่างกิจกรรมทั้งหมด 10 ตัวอย่าง** (ครอบคลุม วิชาการ, จิตอาสา, และค่ายการเรียนรู้)

#### 4.6 Contact & Footer (การติดต่อและส่วนท้าย)
*   **ลักษณะ:** ดีไซน์เรียบง่าย สุภาพ สะอาดตา
*   **องค์ประกอบ:**
    *   ช่องทางการติดต่อ: อีเมล, เบอร์โทรศัพท์, LINE ID
    *   ลิงก์โซเชียลมิเดียเชิงวิชาการ/กิจกรรม: Facebook, Instagram, LinkedIn
    *   Footer Note: Copyright © 2026 [ชื่อนักเรียนผู้สมัคร] - Pre-Med Portfolio CMU

### 5. ข้อจำกัดและข้อกำหนดทางเทคนิค (Constraints & Technical Requirements)
*   **Single File Structure:** โค้ด HTML, CSS (Tailwind classes/Custom styles) และ JS ต้องอยู่ในไฟล์ `index.html` เดียวกัน
*   **Clean Code:** มีการเขียน Comment ภาษาไทยคั่นในแต่ละ Section อย่างชัดเจน เพื่อให้ง่ายต่อการแก้ไขข้อมูล
*   **Asset Management:** รูปภาพประกอบให้ใช้ External Placeholder URL (เช่น `placehold.co`) เป็นตัวแทนไปก่อนในเวอร์ชันเริ่มต้น
